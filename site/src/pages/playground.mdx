# Playground

`@tevm/logger` emits newline-delimited JSON via pino. Set a **logger level** to filter the stream,
then emit logs and watch the raw output.

```ts
import { createLogger } from '@tevm/logger'

const logger = createLogger({ name: 'my-module', level: 'debug' })
logger.info('hello') // logged
logger.trace('noisy') // dropped — below the configured level
```
